# Blinkit Customer Behavior Analysis

# Business Problem

Analyze Blinkit's customer orders and sales data to understand customer behavior, order patterns, and overall performance.

# Questions

1. What is the average number of orders per day?
2. Which customers place the most orders?
3. Which month has the highest number of orders?

# Project Overview

This project analyzes customer behavior and order data to identify simple patterns and useful business insights.

# Tools

Python | Excel | Power BI

# Step by Step Analysis

1. Cleaned the dataset
2. Checked missing values
3. Analyzed customer orders
4. Created basic charts
5. Created a Power BI dashboard

# Key Insights

- Average daily orders were around 1,000.
- Regular customers contributed a large number of total orders.
- Order volume varied across different months.
